├─ {machine}/
│  ├─ telemetry   lot de mesures · QoS 1
│  ├─ state       marche · calage · arrêt
│  └─ alarm       alarme native automate
├─ gateway/{gw}/
│  ├─ status      online retenu · LWT offline
│  ├─ cmd/test    ← back
