# Sécurité

Une faille se signale par l'onglet **Security** du dépôt, bouton « Report a vulnerability ». Le signalement reste
privé jusqu'à sa correction : pas d'issue publique pour ça.

Seule la branche `main` est suivie. Les réglages qui restent à la charge de l'exploitant (domaine, certificats,
codes d'accès, sauvegardes) sont dans [docs/DEPLOIEMENT.md](docs/DEPLOIEMENT.md).
